Omero is a modern multi-tenant content management system (CMS) built with cutting-edge web technologies.

## Features

- Modern React-based architecture
- Type-safe with TypeScript
- Server-side rendering with Vinxi
- Beautiful UI components with TailwindCSS
- Fast and intuitive content management
- Multi-organization (multi-tenant) architecture
- Content versioning and history (revisions)
- Internationalization (i18n) with flexible language settings per organization
- API Keys with granular permission scopes
- SEO-friendly with meta tags, Open Graph, and schema markup
- Role-based access control (RBAC basic - member/admin)
- Soft delete with logical deletion tracking
- Markdown content with custom blocks support
